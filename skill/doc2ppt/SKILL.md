# doc2ppt 文章转 PPT

## 第一步：环境自检（仅首次）

1. 确认 Windows 10/11、Python 3.11–3.13：`python --version`
2. 确认仓库存在：`~/tools/doc2ppt/run.py`。不存在则：
   ```bash
   git clone https://github.com/jxmojx/doc2ppt.git ~/tools/doc2ppt
   python -m pip install -r ~/tools/doc2ppt/requirements.txt
   ```
3. 桌面版 PowerPoint 可选：没有也能生成，但校验降级为估算，终端会出现「校验降级」警告——如实转告用户即可，不算失败。

## 第二步：整理输入

- 用户给的是 .md/.docx/.pdf 文件：直接用，跳到第三步。
- 用户**粘贴纯文本**：先写成 UTF-8 的 `.md` 临时文件，并帮用户补上结构：
  - 文档主标题用 `#`
  - 各章节用 `##`（有编号习惯就保留「一、二、」）
  - 要点用 `-` 列表；数据对比用 GFM 表格（`| 列 | 列 |`）
  - 结构越清楚，出的 PPT 越好；标题层级不要跳级
- 临时文件放系统临时目录，文件名用文章标题（中文可以）。

## 第三步：转换

```bash
python ~/tools/doc2ppt/run.py <输入文件> -o <输出.pptx> --pages 8
```

- `--pages` 期望总页数（含封面），短文 6–8、常规 8–10、长文 12–15；与自然页数差距过大时引擎会按内容自动调整，属预期。
- 用户指定公司/个人模板时加 `-t 模板.pptx`（任意 .pptx，缺版式会自动降级）。
- 转换通常 5–30 秒；**不要并发跑多个转换**（内部串行锁，并发只会排队）。

## 第四步：验收与交付

1. 看终端 `问题数: N`：
   - `0`：直接交付——封面已含日期与页数、正文已条目化、自带页码，**无需人工排版**。
   - `N>0`：如实告知用户哪几页有问题（终端会列出），建议人工过目，不要隐瞒也不要反复重跑。
2. 每页预览 PNG 已导出到 `<项目上级>/preview/<文档名>/`，可挑封面和一页正文给用户确认。
3. 交付时报告：pptx 完整路径 + 总页数 + 是否有降级/警告。
4. 一次成功就够，不要重复生成同一文件。

## 已知边界（提前告知用户）

- 扫描版 PDF（无文本层）只出封面——提示先 OCR。
- 图表仅当表格是 2–8 行纯数字且单位一致时生成；混单位保留表格。
- 两栏版式只用于纯列表页。
- 生成的 PPTX 全部是原生可编辑对象，用户可在 PowerPoint 里改字、改数据、换模板。
